# Contributing

This repository is exported from Morse's private monorepo on each release, so a commit made here would be overwritten by the next export.

- **Issues are welcome.** Open one for a bug, a check that reads wrong, or a question about what the verifier proves.
- **Pull requests are not merged.** If you have a fix, describe it in an issue; we make the change upstream and it ships in the next release.
- **Security problems go through [SECURITY.md](SECURITY.md)**, never a public issue.
